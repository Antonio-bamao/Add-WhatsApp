# Add-WhatsApp 总体计划

## 目标

将现有 WhatsApp Web 自动化脚本升级为 Windows 桌面软件。软件需要支持 CSV/XLSX 导入、复杂电话号码解析、英语/西班牙语/法语模板自动选择、每日限额、随机间隔、扫码登录、发送统计、历史记录和报表导出。

## 阶段与里程碑

### Phase 1: 项目初始化与计划固化

- 初始化 Git 仓库。
- 写入正式计划文档。
- 添加 `.gitignore`，排除登录缓存、客户号码、进度文件、依赖和构建产物。
- 建立 `.context/` 项目记忆。

### Phase 2: 自动化核心重构

- 拆分 `main.js` 为号码解析、语言规则、模板、任务执行和进度存储模块。
- 使用 `libphonenumber-js` 支持不同国家和不同格式的电话号码解析。
- 保留现有 WhatsApp 登录、注册检测和发送能力。

### Phase 3: 桌面软件与打包

- 使用 Electron 实现中文图形界面。
- 支持导入预检、模板管理、发送设置、运行日志、任务控制和报表导出。
- 使用 `electron-builder` 打包 Windows EXE。

## 验收标准

- 用户可双击 Windows 软件启动。
- 用户可导入 CSV/XLSX，并正确解析混合格式电话号码。
- 软件能根据区号和国家列选择英语、西语或法语模板。
- 软件能扫码登录 WhatsApp，并按限额和间隔处理号码。
- 软件能记录成功、失败、未注册、跳过、无效和待确认号码。
- 软件能导出任务明细报表。
