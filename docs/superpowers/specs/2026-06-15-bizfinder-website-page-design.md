# BizFinder 官网子页面设计

## 目标

在 Add WhatsApp 官网新增 `/bizfinder` 子页面，并在现有官网首页导航中增加 BizFinder 入口。页面使用独立的明亮蓝白视觉，面向外贸销售团队介绍 BizFinder 的 Google Maps 商家线索采集能力。

主页面目标不是解释抓取技术，而是让访客快速理解：

> BizFinder 能把手工搜索 Google Maps、逐条复制商家联系方式、整理 Excel 的工作，压缩成一次可控、可暂停、可恢复、可导出的本地获客任务。

## 事实边界

页面文案依据 BizFinder 的 `.context/vision.md`、`master-plan.md`、`design.md` 和当前状态编写。

允许宣传的能力：

- 按国家、地区、城市和行业关键词搜索 Google Maps 商家。
- 采集商家名称、公开电话、地址、坐标、网站、社交链接和来源链接。
- 自定义目标数量，单任务串行执行。
- 实时显示任务进度、采集阶段和错误原因。
- 支持开始、暂停、继续和断点续抓。
- 验证码出现时暂停，由用户手动处理后继续。
- 本地 SQLite 保存任务、结果和日志。
- 商家结果表格排序、筛选和扫描。
- Leaflet / OpenStreetMap 地图标记与表格联动高亮。
- 可选街景或实景查看，不影响主采集流程。
- 同名同地址商家去重。
- 任务历史、新增与已存在统计。
- CSV 和 Excel 导出，支持当前任务、当前筛选和全部结果。
- 采集数据和任务进度默认保留在用户本机。

页面不得承诺：

- 保证抓到目标数量或所有商家电话。
- 自动绕过验证码。
- 云端同步商家数据。
- 定时任务、多任务并发、多个平台混合采集。
- 评论、评分和营业时间采集。
- Google 官方或 Google Maps 合作关系。

## 信息架构

### 1. 官网入口

Add WhatsApp 首页固定导航新增 `BizFinder` 链接，目标为 `/bizfinder`。

BizFinder 页面头部使用：

- BizFinder 横版透明 Logo。
- 锚点导航：产品能力、工作流程、真实界面。
- 返回 Add WhatsApp 的产品入口。
- 主操作按钮：`立即下载`。

下载按钮当前为占位行为，不显示“即将开放”等提示文案，也不触发不存在的文件下载。

### 2. 首屏

主标题：

> 从地图上，找到下一批海外客户

支持文案强调：

- 输入地区和行业关键词。
- 自动整理商家公开电话、网站、地址与位置。
- 把地图搜索结果变成外贸销售可继续跟进的名单。

主按钮为 `立即下载`，次按钮为 `查看如何获客`。

首屏右侧使用代码实现的精致产品界面图，不直接伪装成真实截图。界面包含：

- 搜索条件。
- 地图标记。
- 商家结果列表。
- 电话、网站等状态。
- 采集进度。

### 3. 痛点与价值

用开放布局表达三步人工工作：

1. 在 Google Maps 反复搜索。
2. 逐条打开详情并复制联系方式。
3. 去重后整理进 Excel。

随后转换为 BizFinder 的价值主张：一次创建任务，本地持续整理，结果随时可查。

### 4. 核心能力

避免八张相同卡片堆叠，采用三种不同节奏：

- 大型搜索工作台展示地区、关键词、目标数量和采集控制。
- 横向能力带展示电话、网站、地址、坐标和来源链接。
- 地图与表格联动的双栏产品演示。

### 5. 西班牙球衣店场景

以真实验收场景说明完整工作流：

1. 国家选择西班牙。
2. 输入球衣店相关行业关键词。
3. BizFinder 加载结果并逐条整理商家信息。
4. 错误、验证码或中断均显示明确状态。
5. 最终按筛选条件导出销售名单。

文案不写虚构的客户数量或转化率。

### 6. 稳定性与控制

重点营销表达：

- 随机延迟与可见浏览器模式。
- 验证码时暂停，不静默失败。
- 中断后从断点继续。
- 重复商家自动识别。
- 每个失败阶段都有本地日志。

技术名词只在辅助文案中出现，不让首屏像工程说明书。

### 7. 导出与本地隐私

强调：

- 当前任务、筛选结果和全部结果都可导出。
- CSV 对 Excel 友好。
- XLSX 具有表头和适合阅读的列宽。
- 结果、任务和日志留在本机。

### 8. 真实软件截图

首屏使用精致网站版产品界面图；页面后段展示真实 BizFinder 软件截图，增加可信度。

若实施时仓库内没有可直接使用的截图，则从当前真实软件界面通过本地运行或已有线程资产获取，不使用虚构截图替代。

### 9. 结尾行动区

重复核心结果：

> 少一点复制粘贴，多一批可以继续跟进的海外商家线索。

保留 `立即下载` 主按钮和返回 Add WhatsApp 的次入口。当前下载按钮继续使用占位行为。

## 视觉系统

### 方向

采用用户批准的 A 方案“地图商机工作台”：

- 真白或极浅蓝背景。
- 青绿 BizFinder 品牌色作为主色。
- 天蓝用于地图、水域和辅助信息。
- 琥珀黄来自现有 Logo 数据柱，用于少量强调。
- 深炭色正文，保证明亮页面中的可读性。

### 品牌资产

- 导航与品牌说明使用 `bizfinder-logo-transparent.png`。
- 小尺寸图标和界面角标使用 `icon-512.png`。
- 不重新绘制或修改 Logo 比例。

### 排版

- 中文为唯一主要语言。
- 标题使用紧凑、粗重、现代的无衬线排版。
- 正文维持 16px 以上和舒适行高。
- 不使用装饰性英文眉题作为默认结构。

### 组件语言

- 圆角保持中等，避免所有内容都变成巨型圆角卡片。
- 地图和真实软件截图可以使用更明显的框架与阴影。
- 图标统一使用 Lucide 线性图标。
- 动画集中在地图标记、结果行和滚动进入，不做无意义漂浮。
- 遵守 `prefers-reduced-motion`。

## 技术实现

- 使用现有 Next.js App Router。
- 新增 `website/app/bizfinder/page.js`。
- 根据复杂度拆分 `website/components/BizFinderPage.js` 和必要的局部组件。
- BizFinder 样式追加到现有 `website/public/site.css`，全部使用 `bizfinder-` 前缀，避免污染 Add WhatsApp 页面。
- 品牌图片和真实截图放入 `website/public/bizfinder/`。
- 不引入新的前端框架或 UI 组件依赖。
- 页面 metadata 使用中文标题和描述。

## 响应式与可访问性

- 桌面端首屏为文字与产品界面双栏。
- 平板与手机改为单栏，先文案后产品界面。
- 导航在手机端保留品牌、返回入口和主按钮，隐藏次要锚点。
- 所有按钮至少 44px 高。
- 图片设置明确的替代文本或装饰性空 alt。
- 键盘焦点可见。
- 正文和按钮颜色达到 WCAG AA 对比度。
- 页面不允许横向滚动。

## 验证

- 更新结构测试，锁定 `/bizfinder` 页面、BizFinder 入口、Logo 和营销主文案。
- 运行 `website npm test`。
- 运行 `website npm run build`。
- 使用内置浏览器检查：
  - Add WhatsApp 首页 BizFinder 入口。
  - `/bizfinder` 桌面首屏和完整长页。
  - `立即下载` 占位按钮不会请求不存在的文件。
  - 手机宽度无横向溢出。
  - 页面无 console error。
- 对照批准的 A 方案检查首屏构图、蓝白地图视觉、Logo、CTA 和产品界面。
